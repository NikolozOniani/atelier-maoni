# Photo selection and visual review

All **34 original JPEGs** were opened, decoded and visually inspected using four numbered contact sheets. Five key photographs were additionally examined at a larger size. The archive contains 33 garment photographs and one logo. There were **no unreadable files, corrupt images or byte-identical duplicates**. The archive was treated as unsorted: the categories below come from visible garments, not folder names.

## Art direction and hero

**Image 04** (front view of the silver-embellished fitted dress) is the hero. Its clear embellishment, readable silhouette, soft green background and portrait composition demonstrate intricate work. The original frame does not show the hem: the website preserves that frame rather than suggesting a complete full-length view. Text sits beside the photograph on desktop and above it on mobile, so it never obscures the garment. Warm ivory, charcoal and restrained burgundy complement the silver, green and traditional burgundy garments. Self-hosted Cormorant and Noto Georgian fonts support the two languages.

## Image treatment

The website uses all 33 garment photographs plus the existing 112n.jpg logo, with responsive WebP variants up to each original’s width (maximum 1440px). Orientation is corrected. Embedded profiles, when present, are converted to sRGB; metadata is not copied. Images are not upscaled, recolored or retouched. Only the uniform black letterbox bars of image 08 were removed. Existing camera watermarks in 33/34 remain. Gallery and lightbox images use `object-fit: contain`, so landscape group photographs preserve their full proportions without cropping people or outfits. The hero has priority loading; below-fold photographs load lazily.

The supplied square logo is used intact in the header and footer. Its fine detail is most visible in the review source. No replacement brand artwork was invented.

## Publication review

The owner confirmed that all 33 garment photographs were provided for the atelier portfolio and that relevant parents or guardians consented to publication. Identifiable adults, children, and group-event photographs are therefore included as directed.

The archive, contact sheets, inventory, maintenance data and this document are excluded from standard GitHub Pages output by `_config.yml`. A public GitHub repository can still expose the archive through GitHub itself. Do not bypass these exclusions using `.nojekyll`. Verify the actual Pages output after each deployment.
